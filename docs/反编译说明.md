# Minecraft 26.2 反编译源码说明

> 目的：以后写模组时可以**直接查原版是怎么实现的**，而不是凭记忆猜。
> 本项目已经按本文档的步骤把 26.2 的源码准备好，放在本目录下。

---

## 1. 目录里有什么

```
docs/
├── 反编译说明.md                    ← 本文件
├── minecraft-26.2-sources.jar       ← 反编译产物（单个压缩包，8.3 MB）
└── minecraft-26.2-sources/          ← 上面那个包解压后的源码树
    └── net/minecraft/...            （7056 个 .java 文件，28.3 MB）
```

源码树可以直接用任何文本编辑器打开；用 `rg`（ripgrep）或编辑器的"全目录搜索"功能查代码最快。

## 2. 这份源码是怎么来的

1. 本项目用 Fabric Loom 构建，Loom 自带反编译能力（底层用的是 Vineflower 反编译器）；
2. 在 `mod/` 目录执行 Gradle 任务 `genSources`，Loom 会把 Minecraft 26.2 的
   jar（客户端 + 服务端合并后的那份）整体反编译；
3. 产物是 `minecraft-merged-<哈希>-26.2-sources.jar`，本目录里的两份就是从它复制出来的。

**为什么能反编译得这么干净**：26.2 起 Minecraft 的 jar **本身就没有混淆**
（打开 jar 能看到 `net/minecraft/server/level/ServerPlayer.class` 这样的官方名字），
所以反编译出来的类名、方法名都是官方命名，可直接对照着写模组代码。

## 3. 怎么重新生成（换版本或想更新时）

```powershell
# 在项目根目录
cd D:\MC\MidAutumnMiniGame\mod
.\build.ps1 genSources
```

产物位置（哈希值每次可能不同）：

```
mod\.gradle\loom-cache\minecraftMaven\net\minecraft\
    minecraft-merged-<哈希>\26.2\minecraft-merged-<哈希>-26.2-sources.jar
```

把它解压到 `docs/minecraft-26.2-sources/` 即可覆盖旧版本（解压前先删掉旧目录）：

```powershell
Add-Type -AssemblyName System.IO.Compression.FileSystem
$jar = 'D:\MC\MidAutumnMiniGame\mod\.gradle\loom-cache\...\minecraft-merged-<哈希>-26.2-sources.jar'
$dst = 'D:\MC\MidAutumnMiniGame\docs\minecraft-26.2-sources'
Remove-Item -LiteralPath $dst -Recurse -Force
[System.IO.Compression.ZipFile]::ExtractToDirectory($jar, $dst)
```

> 注意：换 Minecraft 版本（例如升到 26.3）后必须重新生成，源码与版本是一一对应的。
> `gradle.properties` 里的 `minecraft_version` 也要同步改。

## 4. 怎么用它（常用检索方式）

在 `docs/minecraft-26.2-sources` 目录下搜索，例如：

```powershell
$src = 'D:\MC\MidAutumnMiniGame\docs\minecraft-26.2-sources'

# 找某个类的文件
Get-ChildItem "$src/net/minecraft" -Recurse -Filter 'AbstractArrow.java'

# 在某个文件里找方法定义
Select-String -Path "$src/net/minecraft/world/level/Level.java" -Pattern 'public boolean setBlock'

# 全目录搜索某个关键字（看原版在哪些地方用到它）
Select-String -Path "$src/net/minecraft/**/*.java" -Pattern 'UPDATE_CLIENTS' | Select-Object -First 20
```

如果装了 `rg`（ripgrep），搜起来更快：

```powershell
rg -n "onExplosionHit" D:\MC\MidAutumnMiniGame\docs\minecraft-26.2-sources\net\minecraft
```

## 6. 注意事项

- **不纳入 git**：这份源码有 28.3 MB、7000 多个文件，而且属于 Mojang 的版权内容
  （不适合随仓库分发）。`.gitignore` 已排除 `docs/minecraft-26.2-sources/` 与
  `docs/minecraft-26.2-sources.jar`，需要时按第 3 节重新生成即可。
- **仅供本地开发参考**：不要把这份反编译源码再分发或放进公开发布包。
- 反编译结果可能有少量瑕疵（Vineflower 对个别复杂控制流的还原不完美），
  读的时候以方法签名和整体逻辑为准；签名如果想再确认一次，可以用 `javap`：

```powershell
$javap = 'C:\Users\Lenovo\AppData\Local\Programs\Microsoft\jdk-25.0.2.10-hotspot\bin\javap.exe'
$jar   = 'D:\MC\MidAutumnMiniGame\.gradle-home\caches\fabric-loom\26.2\minecraft-merged.jar'
& $javap -p -cp $jar net.minecraft.world.level.Level | Select-String 'setBlock'
```
