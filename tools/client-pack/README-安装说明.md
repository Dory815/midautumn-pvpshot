# 中秋校园枪战小游戏 · 客户端整合包

这是"科大中区 PVP 小游戏"的**客户端整合包**：装好就能进服，包含画面优化、小地图/世界地图、
聊天增强、光影与资源包，以及**已经填好的多人游戏列表**（服务器地址直接在里面）。

## 一、包里有什么

| 目录 / 文件 | 内容 |
|---|---|
| `mods/` | 客户端模组：钠（Sodium）、Iris、ImmediatelyFast、ModMenu、IMBlocker、MouseTweaks、Xaero 小地图 / 世界地图、聊天头像、更多聊天记录、FerriteCore、AppleSkin、Replay 等 |
| `config/` | 各模组的配置文件 |
| `xaero/` | 小地图 / 世界地图的设置与缓存（打开就接着上次的进度） |
| `.voxy/` | Voxy 的远景 LOD 数据与设置 |
| `shaderpacks/` | BSL、Complementary Reimagined 光影 |
| `resourcepacks/` | SPBR 资源包 |
| `servers.dat` | **多人游戏列表**（已含 `<服务器IP>:25566`） |
| `options.txt` | 画面 / 声音 / 键位等游戏设置 |
| `中秋校园枪战小游戏.json` | 版本清单（启动器据此补齐原版 26.2 与 Fabric 库） |

> 包里**不含**客户端主程序 jar（40 MB，启动器会自己下载）和 `.fabric` 缓存（会自己生成），
> 所以第一次启动会花一点时间补齐文件，属正常现象。

## 二、怎么装

### 方式 A：直接扔进版本目录（最省事）

1. 打开启动器（PCL / HMCL），确认已经装好 **Minecraft 26.2 + Fabric**；
2. 把本包解压到 `…\.minecraft\versions\中秋校园枪战小游戏\`（和里面的
   `中秋校园枪战小游戏.json` 放同一层）；
3. 启动器里选中这个版本启动即可。

### 方式 B：用启动器"导入整合包"

在 PCL / HMCL 里选择"导入整合包 / 安装整合包"，选中本 zip；
若提示需要选择版本，选 **26.2 + Fabric**。

## 三、怎么登录（重要）

服务器用的是 **LyerSkin 皮肤站认证**，不能用微软账号直接进：

1. 先去 <https://auth.lylighte.cc/> 注册并创建角色；
2. 在启动器里添加"**外置登录 / 第三方登录**"，地址填
   **`https://auth.lylighte.cc/skinapi`**；
3. 登录并选中你的角色，再启动游戏（**不需要装任何模组就能登录**，启动器会自动处理）。

## 四、怎么进服

多人游戏列表里已经有条目：**`<服务器IP>:25566`**（校园网内可直连）。
服务器还会自动下发一个很小的资源包（定位条上的 A~E 字母图标），下载失败也能正常玩。

## 五、进服后能看到的

- 头顶**血条**与**伤害数字**、死亡处的**尸体**（都是服务端实现的，**只要服务器开着就能看到**，
  和你装不装模组无关）；
- 定位条上的 A~E 点位指示（颜色跟随占领队伍）；
- 音效、命中反馈等你熟悉的原有玩法。

## 六、常见问题

- **进不去、提示验证失败**：说明没有用 LyerSkin 登录（见第三节），或角色没选对。
- **看不到光影**：Iris 需要把光影包放到 `shaderpacks/` 并在"视频设置 → 光影"里启用（包里已放好）。
- **小地图/世界地图数据想重置**：删掉 `xaero/` 目录即可（会丢失已有标记）。
- **Voxy 数据异常**：删掉 `.voxy/` 目录，进服重新加载即可（第一次加载会慢一些）。
- **帧数不够**：把"视频设置 → 渲染距离"降到 12~16；光影关掉或换轻量的。
