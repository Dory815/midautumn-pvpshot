# pvpshot 1.0.0-m1 · 安装说明（服务端模组版）

玩家端**不需要装任何东西**（定位条字母用的资源包由服务器下发）。地图、点位、出生点、
保护区、复原范围全部沿用现有校园存档，不需要改地图。

## 1. 服务端

1. 需要 **Minecraft Java 26.2** + **Fabric Loader 0.19.5**（或更高）+ **Fabric API 0.161.0+26.2**。
2. 把 `模组/pvpshot-1.0.0-m1.jar` 与 Fabric API 放进服务端 `mods/`。
3. 建议再装 Carpet（`/tick` 步进与诊断）与 spark（火焰图），排性能问题很方便。
4. 把现有的校园存档直接作为 `world/`（保留 `pvpshot`、`ustc_pvp` 两个数据包与
   `ustc_pvp:template` 维度）。
5. **数据包补丁**：把 `数据包补丁/ustc_pvp/respawn/` 下的两个文件覆盖到
   `world/datapacks/ustc_pvp/data/ustc_pvp/function/respawn/`，
   然后 `/reload` 或重启服务端。作用与原因见 `数据包补丁/README.md`
   （团队死斗改为始终在基地固定重生点）。
6. `server.properties` 按需设置 `online-mode`、视距等；本模组不新增任何世界格式，
   旧存档可直接开服。

## 2. 服务器资源包（定位条上的 A~E 字母）

`资源包/pvpshot-waypoints.zip` 提供定位条上点位的 A~E 字母图标。把它放到一个可访问的地址，
在 `server.properties` 里配置：

```properties
resource-pack=<下载地址>
resource-pack-sha1=<zip 的 sha1>
require-resource-pack=false
```

- 客户端没加载资源包也能玩，只是定位条上点位显示成默认圆点。
- 算 sha1：`Get-FileHash .\pvpshot-waypoints.zip -Algorithm SHA1`。
- 资源包生成脚本在仓库 `tools/waypoint-resourcepack/make_waypoint_pack.py`。

## 3. 管理员命令

```
/pvpshot match status | on | off | mode three|five|tdm | restart
/pvpshot match visualize on | off | status
/pvpshot restore            # 整场复原（每 tick 限时 5 ms 分帧执行，期间服务器不卡）
/pvpshot restorestatus
/pvpshot protect on | off
```

## 4. 这一版的范围

- 模组已接管：设施保护、整场复原、点位可视化（范围环 / 发光标记 / 定位条航点 /
  信标光柱颜色 / 定位条字母颜色）、全部武器与载具、部署物扣账。
- 仍由数据包驱动：部署物（炮 / 炮塔 / 掩体）、补给箱、大厅与队伍流程、复活流程、
  团队死斗击杀计分、比赛计分（模组比赛引擎默认关闭）。
- 详见 `文档/更新日志.md` 与 `文档/PRD.md`。

## 5. 压测工具（可选）

`压测工具/make_stress_pack.py` 会生成一个测试用数据包 `pvpshot_stress`：

- `function pvpshot_stress:all`：13 种投掷物（箭 / 光谱箭 / 雪球 / 鸡蛋 / 三叉戟 / TNT /
  火球 / 小火球 / 烟花火箭 / 风弹 / 末影珍珠 / 喷溅药水 / 滞留药水）每种 100 发、方向随机，
  从执行位置（也就是玩家身上）向外飞；
- `function pvpshot_stress:clear`：一键清掉这些投掷物（含未爆的 TNT）；
- `function pvpshot_stress:place_kit`：在"执行位置右手边 2 格"摆好压测三件套
  （命令方块 + 按钮 + 告示牌），按钮按下即齐射。

用法：把生成的目录放进 `world/datapacks/`，`/reload` 之后
`execute at <玩家> positioned ~2 ~ ~ run function pvpshot_stress:place_kit`。
注意：齐射会炸地形，测完可以用 `/pvpshot restore` 复原战场。
