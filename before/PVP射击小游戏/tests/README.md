# Java 26.2 引擎回归

测试加载工作区数据包，用官方 GameTest 服务端和模拟玩家检查实际行为。Java 测试入口只用于注册测试函数，发布包不需要 Mod。

```sh
python3 tests/run_gametests.py \
  --java-home /path/to/jdk/Contents/Home \
  --server-jar /path/to/server.jar \
  --work-dir /tmp/pvpshot-regression
```

要求 Java 25 JDK 和官方 Java 26.2 服务端。脚本不下载、不安装运行时。`--work-dir` 必须是专用目录，其中的 `generated-world` 会被重建。输出 `run.log` 与 `report.xml`，数据包解析/加载错误也判为失败。

覆盖内容：

- 20 HP 和实际死亡重生后的生命/装备。
- 雪球 6、蛋 3、配置伤害 7；连续、贴脸、移动与游泳命中；普通投掷物不受影响。
- 雪球成功命中才附加迟缓；盾牌格挡不附减速；护甲、出生抗性、友伤开关和墙体遮挡。
- 向上抛的雪球与鸡蛋以真实原版轨迹落回伤到自己，离手阶段不立即自伤；初始速度未被修改。
- 鸡蛋直击不叠加同次破片、附近投掷者受到 2 HP 破片、墙后玩家不受破片伤害、临时 marker 清理。
- 弓力量 I，弩快速装填 II / 穿透 I，原版实际装填时长 15 tick。
- 实际右键使用火焰弹物品：消耗一发、正确瞄准/归属、原版大火球爆炸且伤害明显高于旧 5 HP（固定测试位置约 14 HP）。
- 原生 TNT 的地形破坏、非固定 8 HP、同几何条件下自伤与敌伤相同、完整/部分遮挡减伤及击杀归属。此对照固定测试 TNT 位置以排除被炸出坑洞后的落点变化，生产代码中的炮弹仍正常受重力影响。
- 两种结构四向部署、重叠拒绝与退款、真实发射器发射与所有权、四向对称扇形箭、炮塔每箭 4 HP、自伤、有限弹药及停止供电。
- 击杀敌队加分、误杀队友扣血但不奖励队伍分数，原版个人击杀归属保留。

新增系统覆盖：

- 连续 20 套随机出生装备均有 16 发雪球、1 枚手雷、铁镐和一件额外随机副武器。
- 手雷实际使用消耗、所有者、抛射初速度、40 tick 引信与原版 TNT 爆炸。
- 两轮真实 16 次雪球使用耗尽弹匣，等待期不能凭空射击，2 秒后反复补满；手动换弹也等待同样时间。
- 满背包不会生成地面弹药，空出一个位置后正常补给。
- 脱战 5 秒内不回血，之后快速恢复；造成/受到伤害立即中断；环境伤害重启等待，最终 3 秒内回满且不溢出。

地图验证在 `tools/test_world/BuildWorld.java` / `build.py` 中：新玩家入场、装备、分队、真实部署、核心区恢复、保留基地改动、重复重置不堆积据点、比分清零、普通玩家 trigger、清除状态、实体按钮补给。构建后的 Anvil 文件还通过 `tools/test_world/inspect.py` 检查元数据、标记与步行连通性。

这不是双客户端视觉验收或服务器压力测试。自定义轨迹判定使用标准玩家体型；半砖、栅栏等按整格保守阻挡。

## 第六轮：服务端设施保护

使用 `server_protection/build.py` 构建 Java 25 标准 agent；`run_gametests.py --suite protection --protection-agent /path/to/pvpshot-protection-26.2.jar` 在官方 26.2 引擎中验证 173 个保护区域、真实挖掘、TNT、步枪、破拆火箭、活塞、箱内物资与取物界面、按钮、部署拒绝以及维护/复原放行。专项 542 项通过；武器回归 55 项、步枪与补给 72 项通过；完整中区构建与 176 批复原的 225 项检查通过。普通战场仍可拆毁，设施保护不改变 TNT 玩家伤害。

服务器模块通过标准 Class-File API 修改加载时的行为，不修改官方服务端 JAR；两个 JAR 都是本项目源码构建，不需要下载第三方依赖。正式 `java -jar server.jar` 启动器采用隔离类加载器，保护判断使用单独的 bootstrap helper，另做真实启动器检查。
