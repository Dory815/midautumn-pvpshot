# 科大中区 PVP 服务端 · Java 26.2

第八轮（2026-09-23）：A、C 改楼顶点，五点信标；新增霰弹枪、大型掩体和三种一次性重武器。高级箱移至点外的地图中线区域。战斗机限时 30 秒，开火、投掷或交战清除药水增益，缓降保留。完整玩法需配套服务端模块，客户端无需 Mod；数值以《武器平衡表.md》为准。温雷：`/trigger pvp_cook`；退出战斗机：`/trigger pvp_land`。
包含官方 `server.jar`、完整中区测试世界和 `pvpshot` / `ustc_pvp` 两个数据包，无需客户端 Mod。80 个普通奖励箱、2 个高级航空箱、100 组掩体与地下基岩层；三点、五点占领和团队死斗可独立切换，顶部计分。生命 20 HP，友伤开启；每条命有无限备弹火焰弹、2 发破拆火箭、手雷、铁镐、64 块队色陶瓦、以及 1 件随机副武器、脱战回血和常满饱食。

本版另附仅服务端运行的设施保护模块。配套启动脚本会自动加载 `protection/` 内的两个 JAR 和保护坐标，保护据点设施、基地和 80 个普通补给箱和 2 个高级航空箱，保留箱子原生界面和 TNT 对玩家的原版结算。不要删除 `protection/` 或绕过启动脚本；普通单人存档不会自动加载此模块。

1. 阅读 https://aka.ms/MinecraftEULA ，同意后自行把 `eula.txt` 的 `false` 改为 `true`。打包时未代为接受协议。
2. macOS 双击 `启动测试服.command`；Linux 执行 `./start.sh`；Windows 运行 `start.bat`。要求 **Java 25**，默认内存上限 **4 GB**；可通过 `PVPSHOT_MAX_MEMORY` 调整。主机还应为系统和客户端留出内存。
3. HMCL 启动 **26.2**，多人游戏 → 直接连接 → `localhost:25565`。局域网玩家连接服务器电脑的局域网 IP，端口 `25565`。
4. 大厅选队即获出生装备；`/trigger pvp_kit` 领取全套测试装备，`/trigger pvp_reset` 分批恢复战场，`/trigger pvp_lobby` 返回大厅。默认五点占领。场地详情见 `场地使用说明.md`。
5. 关闭时在服务器控制台输入 `stop`，等待存档完成。

macOS 启动脚本会查找 HMCL 已下载的 Java 25。其他系统可设置 `PVPSHOT_JAVA` 为 Java 25 可执行文件路径。`./start.sh --check` 只检查环境，不接受协议、不启动服务器。服务器保留 `online-mode=true`，玩家需要可通过正版验证的账号。尚未配置公网访问。

`world/` 是独立副本，不与 HMCL 单人世界共享文件。启动脚本默认允许 12 人，视距 8、模拟距离 6，作为初始测试配置；尚未进行多人压力测试，不能据此承诺并发人数或选定云服务器规格。大型场地恢复会产生额外磁盘和区块加载负载。

## 转为正式服

沿用完整中区世界；用上级目录 `正式服代码/` 里的 `pvpshot` 和 `ustc_pvp` 两个包替换世界对应数据包，再重启。文件夹和 zip 二选一，不能同名重复安装。正式地图包同样对所有玩家开放全套装备、重置、模式切换与移动药水领取、补充奖励箱等大厅按钮及玩法触发命令。管理员另可用：

```
/function ustc_pvp:preset/three
/function ustc_pvp:preset/five
/function ustc_pvp:preset/deathmatch
/function ustc_pvp:reset/start
/function ustc_pvp:mobility/profile_1
```

模式切换开启新局但不修复地形；恢复函数保留所选模式、恢复建筑和玩家搭建区域。保留 `world/dimensions/ustc_pvp/template/`，它是重置所需的原校园方块模板。只装地图数据包不会生成校园或模板。

官方引擎已验证武器、独立模式、地图与恢复逻辑，macOS 启动前检查通过。尚未进行独立服务端双客户端实战与压力测试；Windows 启动脚本未在 Windows 机器上运行。
