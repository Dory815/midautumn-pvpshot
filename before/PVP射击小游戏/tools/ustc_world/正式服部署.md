# 科大中区正式数据包 · Java 26.2

第八轮（2026-09-23）：A、C 改楼顶点，五点信标；新增霰弹枪、大型掩体和三种一次性重武器。高级箱移至点外的地图中线区域。战斗机限时 30 秒，开火、投掷或交战清除药水增益，缓降保留。完整玩法需配套服务端模块，客户端无需 Mod；数值以《武器平衡表.md》为准。温雷：`/trigger pvp_cook`；退出战斗机：`/trigger pvp_land`。
使用 Java 25 和 Minecraft Java 26.2；服务端数据包配合设施保护模块，客户端不需要 Mod。

## 安装

1. 从配套测试服务端复制完整 `world/`，或使用完整 `USTC_PVP_Field_26.2` 存档作为服务端世界。数据包本身不包含校园地形。
2. 替换 `world/datapacks/` 下的 `pvpshot` 和 `ustc_pvp` 为本目录版本。每个包使用文件夹或 zip 其中一种，不要重复安装。
3. 保留世界的 `dimensions/ustc_pvp/template/` 及世界数据文件，供地形恢复使用。开启 PVP，出生保护设为 0。命令方块游戏规则已随配套世界启用。
4. 玩家在大厅选队。大厅控制按钮及玩法触发命令向所有玩家开放，模式与恢复操作见下文。

5. 同时保留服务端 `protection/` 和 `protection-required.txt`，使用本版启动脚本加载保护模块。手工部署时将正式目录的 `protection/` 复制到服务器根目录并使用配套启动脚本。只更新数据包不能保护原版挖掘和 TNT 爆炸；说明见 `protection/说明.md`。

`pvpshot` 是武器、队伍、回血、弹药和独立模式核心。`ustc_pvp` 是本校园的点位、基地、补给、移动效果及地形恢复逻辑。地图包的 load/tick 标签显式接入核心，应排在核心之后；完整存档已经设置顺序。

## 管理比赛

```
/function ustc_pvp:preset/three
/function ustc_pvp:preset/five
/function ustc_pvp:preset/deathmatch
/function ustc_pvp:reset/start
/function ustc_pvp:mobility/profile_1
```

前三项选择三点、五点或死斗，并清零归属/比分、重新发放每条命装备。恢复函数分批修复中区建筑/道路，去除玩家搭建，重建据点/基地/补给，再开始新局；保留所选模式，等待顶部进度完成后再发起下一次恢复。不要在恢复中反复调用管理函数。

出生不默认添加移动效果。大厅的 `profile_0` 按钮领取速度 V 药水，`profile_1` 按钮领取跳跃 V 药水；均持续 45 秒。

正式地图包与配套测试世界均配置 `#test.controls=1`，所有玩家都可以使用大厅按钮补齐装备、恢复地形、切换模式或移动档位、补充奖励箱，无需 OP。玩法命令为 `/trigger pvp_kit`、`/trigger pvp_reset`、`/trigger pvp_lobby`，以及 `/trigger ustc.mode set 3`、`set 5`、`set 1`（三点、五点、死斗）。上述 `/function` 形式供管理员或控制台使用。

恢复期间重复请求不会让进度归零；完成后有 15 秒冷却，请按提示等待。

配置文件为 `ustc_pvp/data/ustc_pvp/function/configure.mcfunction`；通用参数在 `pvpshot/data/pvpshot/function/cfg/`。`/reload` 会重读配置并重开当前地图预设。自定义地图应另建布局，不要在不相关世界调用 `ustc_pvp:build`。

## 当前规则与验证

20 HP、友伤开启、TNT 原版结算。每条命 16 发无限备弹火焰弹（2 秒换弹）、2 发破拆火箭、1 枚手雷、铁镐、64 块队色陶瓦、1 件随机副武器；脱战 5 秒后快速回血，饱食度常满。敌军受伤后全员可见发光 2 秒。占点只按归属产分；死斗只奖励击杀敌队。三点目标 600、五点 1000、死斗 60。

布局见 [中区地图说明](中区地图说明.md)，武器见 [武器平衡表](武器平衡表.md)，移动依据见 [移动能力评估](移动能力评估.md)。原校园不改写；对战使用独立副本。官方引擎已验证地图恢复、真实重生、模式和武器；尚未进行多人实战与并发压力测试。
