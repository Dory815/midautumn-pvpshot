# 科大中区 PVP：玩家安装简明教程

适用版本：Minecraft Java **26.2 正式版**。启动器里的版本名是 `26.2`。客户端使用原版即可，不需要安装 Forge、Fabric 或其他 Mod。

**先准备游戏**

1. 打开 HMCL，在游戏安装/下载页面选择 **26.2 正式版**并安装。
2. 在该版本的游戏设置中选择 **Java 25**；如果启动器提示缺少 Java，按提示下载对应运行环境，再选择它启动游戏。
3. 成功进入游戏主菜单后，根据下面的用途操作。

Java 版本依据：[Minecraft 官方 Java 25 要求](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-1)。本项目发布包已按 Java 25、Minecraft 26.2 验证。

**一起玩现有服务器：无需下载数据包**

1. 打开 [LyerSkin](https://auth.lylighte.cc/)，注册或登录自己的账号，确认已有可用的游戏角色。
2. 在 HMCL 的账号管理中选择添加认证服务器／外置登录，认证地址填写 `https://auth.lylighte.cc/skinapi`。按启动器提示登录自己的 LyerSkin 账号，并选中角色。
3. 选中这个 **LyerSkin 账号**启动 26.2。已经打开的游戏需要退出并重新启动，切换启动器账号不会改变正在运行的游戏会话。
4. 游戏内进入「多人游戏」→「添加服务器」，地址填写 `<服务器IP>:28898`，保存并加入。此地址已在校园网测试；校外连接尚未验证。
5. 进入大厅，按「加入红队 / 加入蓝队」按钮，即可自动领取出生装备。

现有服务器使用 **LyerSkin 外置账号验证**；离线账号或普通微软账号会话不能直接加入。HMCL 负责加载外置登录组件，客户端不需要手动安装游戏 Mod。武器、地图和设施保护都由服务器提供，玩家不用往本地 `datapacks`、`mods` 或 `resourcepacks` 放文件。

如遇用户名／会话验证失败，先确认选中的是 LyerSkin 账号，再在 HMCL 中重新登录并完整重启游戏。26.2 请使用支持该版本的 HMCL 和认证组件；服务端使用官方 authlib-injector 1.2.8。[authlib-injector 官方发布记录](https://github.com/yushijinhun/authlib-injector/releases)

**本机完整测试：启动配套服务端**

第八轮的弓弩距离伤害、战斗机、温雷、冲锋枪连射和风弹需要服务端模块。分享完整玩法请发 `PVP测试服务端-26.2.zip`；解压后阅读 EULA，同意后把 `eula.txt` 改为 `eula=true`，用 `start.bat`（Windows）或 `启动测试服.command`（macOS）启动，游戏里连接 `localhost:25565`。客户端无需安装 Mod。

**仅查看地图和数据包：导入单人存档**

需要分享的文件：`科大中区-霜蚀雪球-26.2.zip`。名称保留自雪球更新轮次；当前这份存档已同步第八轮数据包。

1. 退出游戏，解压 ZIP，找到 `USTC_PVP_Field_26.2` 文件夹。打开后应直接看到 `level.dat`、`region`、`datapacks` 等内容。
2. 在 HMCL 中选中 **26.2**，通过该版本的文件夹入口打开其实际游戏目录，再打开 `saves`。如果没有 `saves`，可自行新建。
3. 把整个 `USTC_PVP_Field_26.2` 文件夹复制到 `saves` 中；保留完整内容，包括地形恢复用的 `dimensions`。若已有同名存档，请先备份或把新副本改名，避免覆盖进度。
4. 确认目录层级为 `saves/USTC_PVP_Field_26.2/level.dat`，不要在中间多套一层同名文件夹。
5. 启动 26.2 →「单人游戏」→「科大中区 · 霜蚀雪球测试」，进入大厅后选队。

完整存档已经包含两个数据包，无需再次安装。HMCL 开启版本隔离后，`saves` 可能在 `.minecraft/versions/该版本/` 下，所以应从启动器打开该版本目录。[HMCL 官方版本隔离说明](https://docs.hmcl.net/launcher/isolation.html)

测试存档常用命令：

```mcfunction
/trigger pvp_kit
/trigger pvp_reload
/trigger pvp_lobby
/trigger pvp_reset
```

依次为：领取全套测试装备、手动换弹、回大厅、恢复战场。当前服务器和测试存档均对所有玩家开放这些命令及大厅按钮，无需 OP。恢复时等待屏幕顶部进度结束，完成后有 15 秒冷却。

选择模式也可输入 `/trigger ustc.mode set 3`（三点）、`/trigger ustc.mode set 5`（五点）或 `/trigger ustc.mode set 1`（死斗）。模式切换会开新局，修复地形需另外执行重置。

普通单人存档不会加载服务端模块，因此不能完整测试本轮新武器、战斗机、温雷与设施保护；完整功能请使用上面的本机服务端。

需要在本机获得完整玩法与设施保护时，使用 `PVP测试服务端-26.2.zip`：解压并阅读其中的 `开服说明.md`；自行阅读并同意 EULA 后将 `eula.txt` 改为 `eula=true`，用 Windows 的 `start.bat`、macOS 的 `启动测试服.command` 或 Linux 的 `./start.sh` 启动，再从游戏「多人游戏」连接 `localhost:25565`。结束时在服务器窗口输入 `stop`。此分发包默认仍开启正版验证；如需允许离线昵称，先停服，在 `server.properties` 中设置 `online-mode=false` 和 `enforce-secure-profile=false` 后再启动。同名配置如已存在应修改原行。

**只安装武器数据包到自己的测试世界**

1. 用 26.2 新建一个允许命令的测试世界，进入一次后保存退出。核心包会调整游戏规则和装备，并在首次初始化时放置简易设施，建议使用专用测试世界。
2. 把 `pvpshot-26.2.zip` 原样放进 `saves/你的世界/datapacks/`，ZIP 不用解压。不要放进 `mods` 或 `resourcepacks`，也不要同时安装同一个包的文件夹和 ZIP。
3. 重新进入世界，输入 `/reload`，再输入 `/datapack list enabled`，确认启用列表里有 `pvpshot`。核心包会自动初始化玩家装备。

`ustc_pvp-26.2.zip` 是中区地图逻辑包，需配套完整中区存档。单独安装它不会生成校园，也不会得到地形恢复模板。只安装 `pvpshot` 可查看基础数据包逻辑；第八轮完整玩法还需配套服务端模块。

给朋友分享时：联机玩家发服务器地址和本教程；本地完整体验发配套测试服务端 ZIP；只研究武器系统发 `pvpshot-26.2.zip`。

第八轮控制：按住鸡蛋冲锋枪右键自动连射；`/trigger pvp_cook` 切换温雷；`/trigger pvp_land` 退出战斗机。弓飞出 20 格后才启用 0.75 格近炸，弩 20 格内低伤、远程致命且装填 3 秒。

第八轮新增：霰弹枪、大型掩体、轨道 380、飞鹰 500、空爆火箭筒；战斗机 30 秒到期退出。A/C 在楼顶，站上北侧中央黏液块可弹射上楼，跳水平台下方有水池。独立高级箱坐标及完整参数见《武器平衡表.md》。
